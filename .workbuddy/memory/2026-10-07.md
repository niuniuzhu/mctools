### 登录识别踩坑（重要）
- 商店登录**不是 cookie**，而是把 token 存在 `localStorage['mctools-auth-token']`，请求时带 `Authorization: Bearer <token>`（见 store.html 的 `loadAccountState()`）。新接口只靠 cookie 会一直 401。
- 服务端有两套会话：`getCommunitySessionFromRequest`（cookie `mctools_community` 或 Bearer）、`getSessionFromRequest`（cookie `mctools_session`）。新接口统一用 `getStoreAccountSession()` = community 优先、public 兜底。
- 前端每个 fetch 都要带 `authHeaders()`：`Object.assign(extra, token ? { Authorization: 'Bearer ' + token } : {})`。
- 排查手法：`curl -H "Authorization: Bearer <token>" http://127.0.0.1:3004/api/store/points` 直接验服务端；token 可从 `data/users.db` 的 `auth_sessions` 表取。

- 商品卡 card-actions 加 `.wish-btn`（`data-wishlist-toggle`），点击切换收藏，存 `mctools-store-wishlist`（localStorage，只存 productCode 数组）。
- 功能分区加「我的收藏」按钮（`data-wishlist-filter`），点击把商品网格筛成收藏夹；`wishlistOnly` 与分类/搜索/排序并列计入 `filtering`，重置按钮也会清掉。
